* Introduction

Kobold scribes started out as a project for the Project Course at my University. It was meant to be a contained project that was very limited in scope, a strategy game built in Raylib that focused on trade.

I consider it a success, despite the unbalanced and simple nature of it. But after trying to expand upon it after the course was done (as I had planned) I quickly got bogged down in code that was written weeks ago with different systems in mind. I needed a hard reset of the Project.

After some advice from my councillor, I decided to do it this time in SDL to allow me even more freedom and control over what happens, and especially so that the implementation of multiplayer, one of the things I had planned for from the start could be done.

This time I use all the knowledge I have gathered, not only for how the game should be structured from a game design/code point of view but also how I should handle documentation/work ethic to try and create a more solid foundation that I can use to create the my dream game.

The ultimate goal of this project is to be a multiplayer game I can play and develop with my friends but also a game suited for machine learning AI to be tested upon during my Thesis Project.
